# Maze Generator API - Dart/Flutter Client

Maze Generator creates random mazes using recursive backtracking algorithm with customizable size and difficulty.

[![pub package](https://img.shields.io/pub/v/apiverve_maze.svg)](https://pub.dev/packages/apiverve_maze)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This is the Dart/Flutter client for the [Maze Generator API](https://apiverve.com/marketplace/maze?utm_source=dart&utm_medium=referral&utm_content=readme).

## Installation

Add this to your `pubspec.yaml`:

```yaml
dependencies:
  apiverve_maze: ^1.2.5
```

Then run:

```bash
dart pub get
# or for Flutter
flutter pub get
```

## Usage

```dart
import 'package:apiverve_maze/apiverve_maze.dart';

void main() async {
  final client = MazeClient('YOUR_API_KEY');

  try {
    final response = await client.execute({
      'width': 15,
      'height': 15,
      'difficulty': 'medium',
      'image': true,
      'solutionImage': true
    });

    print('Status: ${response.status}');
    print('Data: ${response.data}');
  } catch (e) {
    print('Error: $e');
  }
}
```
