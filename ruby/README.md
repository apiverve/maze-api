# Maze Generator API - Ruby Gem

Maze Generator creates random mazes using recursive backtracking algorithm with customizable size and difficulty.

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'apiverve_maze'
```

And then execute:

```bash
$ bundle install
```

Or install it yourself as:

```bash
$ gem install apiverve_maze
```

## Getting Started

Get your API key at [APIVerve](https://apiverve.com)

### Basic Usage

```ruby
require 'apiverve_maze'

# Initialize the client
client = APIVerve::Maze::Client.new(api_key: "YOUR_API_KEY")

# Make a request
response = client.execute({
  width: 15,
  height: 15,
  difficulty: "medium",
  image: true,
  solutionImage: true
})

# Print the response
puts response
```


### Error Handling

```ruby
begin
  response = client.execute({ width: 15, height: 15, difficulty: "medium", image: true, solutionImage: true })
  puts response["data"]
rescue APIVerve::Maze::ValidationError => e
  puts "Validation error: #{e.errors.join(', ')}"
rescue APIVerve::Maze::APIError => e
  puts "API error: #{e.message}"
  puts "Status code: #{e.status_code}"
end
```

### Debug Mode

```ruby
# Enable debug logging
client = APIVerve::Maze::Client.new(
  api_key: "YOUR_API_KEY",
  debug: true
)
```
